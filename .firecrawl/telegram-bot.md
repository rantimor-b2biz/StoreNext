# 🤖 Claude Telegram Bot

[Permalink: 🤖 Claude Telegram Bot](https://github.com/rantimor-b2biz/telegram-claude-bot#-claude-telegram-bot)

Control Claude from anywhere in the world via Telegram. Work on all your workspace projects remotely.

**🇮🇱 Hebrew documentation:** See [README-HEBREW.md](https://github.com/rantimor-b2biz/telegram-claude-bot/blob/main/README-HEBREW.md)

* * *

## ✨ Features

[Permalink: ✨ Features](https://github.com/rantimor-b2biz/telegram-claude-bot#-features)

- 🌍 **Remote access**: Send instructions to Claude from anywhere via Telegram
- 📁 **Multi-project**: Access all workspace projects, not just one
- 📤 **File transfer**: Request files and bot sends them via Telegram
- ✏️ **File editing**: Update files through conversation
- 🔒 **Secure**: Only you can use the bot (user ID authentication)
- 💬 **Context memory**: Bot remembers conversation context (10 messages)
- 🚀 **Fast**: Instant responses, no polling delays

* * *

## 🚀 Quick Start (5 minutes)

[Permalink: 🚀 Quick Start (5 minutes)](https://github.com/rantimor-b2biz/telegram-claude-bot#-quick-start-5-minutes)

### 1\. Get Tokens

[Permalink: 1. Get Tokens](https://github.com/rantimor-b2biz/telegram-claude-bot#1-get-tokens)

**Telegram Bot Token:**

1. Open Telegram → Search `@BotFather`
2. Send: `/newbot`
3. Follow prompts, copy the token

**Claude API Key:**

1. Go to: [https://console.anthropic.com/](https://console.anthropic.com/)
2. Login/signup
3. Navigate to **API Keys** → **Create Key**
4. Copy the key

**Your Telegram User ID:**

1. In Telegram → Search `@userinfobot`
2. Send: `/start`
3. Copy your user ID number

### 2\. Install

[Permalink: 2. Install](https://github.com/rantimor-b2biz/telegram-claude-bot#2-install)

```
cd telegram-claude-bot
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your tokens
```

### 3\. Run

[Permalink: 3. Run](https://github.com/rantimor-b2biz/telegram-claude-bot#3-run)

```
python bot.py
```

Or double-click: **`start-bot.bat`** (Windows)

### 4\. Test

[Permalink: 4. Test](https://github.com/rantimor-b2biz/telegram-claude-bot#4-test)

1. Open Telegram
2. Search for your bot
3. Send: `/start`
4. 🎉 Done!

## 🐛 Troubleshooting

[Permalink: 🐛 Troubleshooting](https://github.com/rantimor-b2biz/telegram-claude-bot#-troubleshooting)

**Bot doesn't respond:**

- Check bot is running
- Verify `.env` values are correct
- Check User ID matches yours

**API key error:**

```
❌ Error: CLAUDE_API_KEY not set
```

→ Ensure `.env` file exists with correct API key

**Bot token error:**

```
❌ Error: TELEGRAM_BOT_TOKEN not set
```

→ Ensure `.env` file exists with correct token

**Unauthorized error:**
→ Check `TELEGRAM_USER_ID` in `.env` matches your ID

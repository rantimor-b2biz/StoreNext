# B-brain: StoreNext Market Intelligence & Learning

**Directory:** Research, insights, learning logs, customer feedback, market data

## Overview

This directory contains everything the team learns, discovers, and documents about the market, customers, competitors, and our performance.

**Purpose:** Single source of truth for market intelligence and customer insights
**Audience:** Entire marketing team
**Update Frequency:** Continuous (learning log daily, market reports weekly, feedback as it arrives)

## 🎯 What Goes In Each File

### messaging-matrix.md
- Primary personas (CFO, Procurement, CIO)
- Their pain points and problems
- Best messages for each persona
- Proof points and data
- Triggers for using each message
- Channel recommendations

### content-opportunities.md
- Emerging trends (SEO, social, industry)
- Content gaps we can fill
- Competitive content we can counter
- Seasonal opportunities
- Customer questions from support

### learning-log.md
- Daily discoveries and insights
- What campaigns worked and why
- What didn't work and lessons learned
- Customer quotes and feedback
- Market trends noticed
- Competitive moves observed
- Team insights and suggestions

**Format:**
```
## [Date]

### Wins/Learnings
- [Discovery 1]
- [Discovery 2]

### What Didn't Work
- [Lesson 1]
- [Lesson 2]

### Customer Insights
- [Feedback quote]
- [Behavior observation]

### Next Actions
- [What to test/explore]
```

### feedback.md
- Customer testimonials
- Sales team feedback
- Support team feedback
- Market reactions to campaigns
- Objections and how to handle them
- Questions prospects ask

### decisions.md
- Strategic decisions made
- Reasoning for each decision
- Date of decision
- Who was involved
- How to implement
- Expected outcomes

**Format:**
```
## [Decision Title]

**Date:** [Date]
**Decision:** [What was decided]
**Reasoning:** [Why this choice]
**Alternative:** [What else we considered]
**Owner:** [Who's implementing]
**Status:** [In progress/Completed]
**Outcome:** [Results so far]
```

## 🔄 Learning Loop

1. **Observe** — Track metrics, customer feedback, market signals
2. **Record** — Log in learning-log, feedback, decisions files
3. **Analyze** — Share in weekly standup
4. **Apply** — Adjust strategy, content, campaigns based on learnings
5. **Repeat** — Continuous improvement cycle

## 💡 How to Use This Data

### For Content Planning
1. Check `content-opportunities.md` for gaps
2. Review `messaging-matrix.md` for persona messaging
3. Check `learning-log.md` for what topics resonate
4. Create content addressing those gaps

### For Campaign Strategy
1. Review `ads-performance/` for what's working
2. Check `feedback.md` for customer objections
3. Review `learning-log.md` for market trends
4. Design campaigns testing new approaches

### For Sales Enablement
1. Check `feedback.md` for common objections
2. Review `decisions.md` for strategic context
3. Use `messaging-matrix.md` for persona messaging
4. Build sales collateral addressing top objections

### For Decision-Making
1. Check `learning-log.md` for past learnings
2. Review `decisions.md` for previous context
3. Use `messaging-matrix.md` for strategic alignment
4. Make decisions informed by data

## ⚠️ Sensitive Data

**API Keys & Credentials:**
- Stored in `google-auth/` (encrypted)
- Never share publicly
- Rotate quarterly
- Document in `api-keys-registry.md`

**Customer Data:**
- Use company names only (not employee names)
- No confidential information
- General feedback themes only
- Customer approval for case studies

**Competitive Intelligence:**
- Document what competitors do
- Analyze publicly available info only
- Never share proprietary methods
- Focus on market gaps we can fill
